Wire up continuous integration so the full self-check runs on every push and
pull request: install the test and analysis tooling, then run the project's
verify script as a single job.

Make the job fail on any red, and make the output readable when it fails —
a CI run that only says "something went wrong" wastes everyone's time. Once
it is green on the first run, run it again on a clean runner to prove it does
not depend on local state.
