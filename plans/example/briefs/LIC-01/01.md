make sure every third-party asset in the tree is compatible with it: code
copied from elsewhere, bundled fonts, icons, data files and generated assets.

For each third-party piece, record its name, version and license in a NOTICE
file. If any dependency's license is incompatible, stop and report it rather
than shipping — license problems are not something to paper over.
